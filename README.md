# 🛠️ PCB Servomoteurs & Moteurs – Coupe de France de Robotique 2026

![Made for Coupe de France de Robotique 2026](https://img.shields.io/badge/Made%20for-Coupe%20de%20France%20de%20Robotique%202026-blue)

Ce projet est un PCB dédié au pilotage de **moteurs** et **servomoteurs**, conçu pour la **Coupe de France de Robotique 2026**.

## ⚙️ Fonctionnalités principales

- Contrôle de servomoteurs via :
  - **UART**
  - **PWM**
- Carte en **4 couches** avec une **couche Power** divisée en 3 zones.

# 🛠️ PCB for Servomotors & Motors – French Robotics Cup 2026

![Made for Coupe de France de Robotique 2026](https://img.shields.io/badge/Made%20for-Coupe%20de%20France%20de%20Robotique%202026-blue)

This project is a PCB designed to control **motors** and especially **servomotors**, built for the **French Robotics Cup 2026**.

## ⚙️ Key Features

- Supports two control modes for servos:
  - **UART**
  - **PWM**
- Built on a **4-layer board** with a **Power layer** split into 3 zones.
